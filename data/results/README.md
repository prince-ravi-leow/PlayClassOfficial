# Results

Pipeline outputs, organised by stage.

| Directory              | Description                                                                       |
| ---------------------- | --------------------------------------------------------------------------------- |
| `tracking/`            | Tracker inference outputs (per-variant, per-video).                               |
| `eval_tracking/`       | Tracker evaluation benchmark (ground truth, predictions in MOT format, metrics).  |
| `eval_classification/` | Classification checkpoints and evaluation artefacts.                              |
| `clustering/`          | Unsupervised clustering grid search (silhouette scores, scaled feature matrices). |
