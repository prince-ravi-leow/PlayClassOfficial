# Classification Evaluation

LOCO cross-validation results for play-behaviour classification (social class
excluded). All models trained with inverse-square-root class weighting and label
smoothing (0.1) unless noted. Values are pooled test macro-F1 (%) ± fold-level
SD across 5 LOCO folds.

Generated by `pipeline/eval_classification.py tables`.

## Per-run directory structure

Each timestamped subdirectory contains a single training run:

| File                                | Description                                |
| ----------------------------------- | ------------------------------------------ |
| `cfg.json`                          | CLI arguments for reproducibility.         |
| `loco_summary.csv`                  | Per-fold and aggregate scalar metrics.     |
| `loco_{split}_confusion_matrix.txt` | Summed confusion matrix (train/val/test).  |
| `loco_{split}_confusion_matrix.npy` | Confusion matrix as NumPy array.           |
| `fold_{i}_{cage}/`                  | Per-fold checkpoints and CSVLogger output. |
| `train.log`                         | Training log.                              |

## Reproducing

```sh
pixi run eval_classification tables
```
