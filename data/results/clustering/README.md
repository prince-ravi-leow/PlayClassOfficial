# Clustering

Unsupervised clustering analysis of morphokinematic features to assess whether
play behaviours form natural groupings independent of human labels.

Generated by `pipeline/clustering_grid.py`, which runs a k x solver silhouette
grid search over standardised windowed features (social windows excluded).

## Files

| File              | Description                                                         |
| ----------------- | ------------------------------------------------------------------- |
| `Z_dropna.npy`    | StandardScaler-transformed feature matrix (rows with NaN dropped).  |
| `grid_dropna.csv` | Silhouette scores for each (solver, k) combination over `Z_dropna`. |

## Solvers

Four clustering algorithms are compared (defined in `src/clustering`):

- **k-means** (sklearn)
- **k-medoids** (FasterPAM, Euclidean)
- **HAC** (Ward linkage, Euclidean)
- **GMM** (Gaussian mixture)

## Reproducing

```sh
pixi run clustering_grid
```
